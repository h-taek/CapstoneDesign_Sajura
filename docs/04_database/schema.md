# DB 스키마 설계서

## 현재 작성 가능 범위

기술 문서 기준 DBMS는 MySQL이며, 사용자, 매장, 재고, 매출, 예측 결과를 저장한다.

## 1. DBMS

- MySQL

## 2. MySQL 선정 이유

- Docker 기반 배포가 용이하다.
- 복잡한 쿼리 및 JSON 필드를 지원한다.
- DB 인덱싱, 파티셔닝, 슬레이브 복제를 통한 확장 대응이 가능하다.
- 오랜 기간 활용된 오픈 소스로 정보가 많다.
