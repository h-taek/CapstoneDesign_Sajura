## 2. 학습 데이터 사용 방식 — 미정 (슬라이딩 윈도우 적용 여부 포함)

> spec(`ml_pipeline.md` §2, `model_spec.md` §7)에 "슬라이딩 윈도우 방식 / 최근 N개월" 표현이 있었으나, 방식 자체가 확정 안 됨. spec에서 관련 내용 모두 제거하고 본 §2에서 후보 비교 후 역반영.

### 2.1 학습 데이터 사용 방식 후보

| 방식 | 설명 |
|---|---|
| 슬라이딩 윈도우(N개월) | 항상 최근 N개월만 학습, 그 이전 데이터는 자동 제외 |
| 전체 데이터 누적 학습 | 모든 과거 데이터 동일 가중치로 사용 |
| 시간 가중치 부여 학습 | 모든 데이터 사용하되 최근 데이터에 큰 가중치 (exponential decay 등) |
| 시즌별 분할 학습 | 시즌·요일 등 패턴별로 모델 분리 |

### 2.2 슬라이딩 윈도우 선택 시 N 값 후보

- 매장 운영 특성상 의미 있는 학습 구간(3·6·12개월) 비교
- 계절성 반영을 위한 최소 윈도우 길이
- 점주 메뉴 변경·매장 리뉴얼 등 도메인 변화 대응 방식

### 2.3 probe 후 spec 역반영 대상

- `ml_pipeline.md` §2 실행 방식
- `model_spec.md` §7 학습 방식

## 3. 결측·이상치 처리 기준 — 상세 정의 필요

> spec(`ml_pipeline.md` §6, `feature_spec.md` §4.6 등)에는 "이상치/결측값을 탐지·처리한다"는 사실만 남기고, 탐지 방법·임계값·처리 정책은 본 §3에서 확정 후 spec에 역반영한다.

### 3.1 결측값 보간 방법

- 후보: 전일 평균·이동평균·0 채움·같은 요일 평균 등
- 컬럼별 적용 매핑 미정 (매출/날씨/유동인구 등)
- "결측 비율이 너무 높을 때" 분리할지 보간할지 분기 기준 미정

### 3.2 이상치 탐지 방법

- 후보: **IQR / Z-score** (둘 다 사용 가능)
- 컬럼별 적용 조건 미정 (어떤 컬럼은 IQR, 어떤 컬럼은 Z-score)
- 임계 계수 미정 (IQR 배수 1.5 / Z-score 컷오프 3.0 등)
- 분포 정규성 확인 후 컬럼별 결정 필요

### 3.3 이상 데이터 처리 정책 (spec에서 이동한 잠정값)

> 아래는 spec에서 "확정"으로 적혀 있던 잠정 정책을 옮긴 것. AI probe 후 정량 기준이 검증되면 spec에 역반영.

- **잠정 처리 분기**:
  - 이상치 비율 5% 미만 → 자동 분리, 알림 없음
  - 이상치 비율 5% 이상 → 점주 알림, 복구/폐기 선택
- **잠정 분리 정책**: 이상 데이터는 학습 데이터에서 분리 (수정/유지 선택지 미정)
- **5% 임계값 자체** 및 알림 트리거 조건은 probe 후 확정
- **이상치 비율 산출 단위** (전체 행 대비 / 컬럼별 / 일자별) 미정

### 3.4 probe 후 spec 역반영 대상

- `feature_spec.md` §4.6 데이터 품질 처리 표(처리 분기·알림 트리거)
- `feature_spec.md` 알림 채널 표(이상치 5% 이상 감지)
- `sequence.md` 판매 데이터 동기화 시퀀스의 이상치 분기 블록
- `user_flow.md` 알림 이동 화면 표의 이상치 항목

## 6. 재학습 후 모델 교체·배포 승인 기준 — 미정

> "교체 기준"(새 모델 vs 기존 모델 비교 후 어느 시점에 바꿀까)과 "배포 승인 기준"(자동/수동·승인 권한·롤백)은 같은 결정 사슬이므로 본 §6에서 통합 결정한다. 결정 후 `docs/spec/08_ai/ml_pipeline.md` §10 미확정 안내에서 "배포 승인 기준" 제거 + spec 본문에 정책 반영.

조사 필요:
- 재학습 후 성능 비교 지표·임계값(MAPE 개선 폭 등)
- 자동 교체 vs 수동 검토 후 교체
- 점진적 배포 여부(카나리·A/B 테스트)
- 롤백 절차 및 트리거 조건
- 모델 버전 보존 정책 (→ §7 모델 버전 관리와 연계)
