# Frontend 조사 (예정)

> **목적**: Frontend(React/PWA) 구현에 활용 가능한 오픈소스·라이브러리·도구를 카테고리별로 조사한다.
> **연결 spec**: `docs/spec/07_backend/service_design.md`, `docs/spec/04_flow/user_flow.md`, `docs/spec/03_feature_design/feature_spec.md` (UI 구성)

---

## 조사 예정 카테고리

| 카테고리 | 내용 |
|----------|------|
| 프레임워크·번들러 | React · Vite · Next.js 등 |
| 상태 관리 | Zustand · Redux Toolkit · Jotai · TanStack Query |
| UI 라이브러리 | shadcn/ui · MUI · Mantine · Chakra |
| 폼·검증 | React Hook Form · Zod |
| PWA·오프라인 | Workbox · vite-plugin-pwa |
| 인증·HTTP | axios · ky · fetch wrapper, OAuth 콜백 처리 |
| 차트·시각화 | Recharts · Visx · ECharts (수요예측·대시보드) |
| 라우팅 | React Router · TanStack Router |
| 알림·푸시 | Service Worker · Web Push API |
| 테스트 | Vitest · Playwright · MSW |
| 코드 품질 | ESLint · Prettier · TypeScript |
| 배포·번들 | Vercel · GitHub Pages · Cloudflare Pages |

각 카테고리별 후보 비교는 `research/backend/` 폴더의 양식을 따른다.
