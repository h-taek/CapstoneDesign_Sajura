# MVP 범위 정의서

## 현재 작성 가능 범위

기술 문서에는 초기 MVP 범위 설정이 필요하다고 명시되어 있다. 또한 MVP 단계에서 업종 범위를 카페/치킨집 등 단일 업종으로 제한하여 초기 검증을 수행하는 개선 방향이 제시되어 있다.

## 1. MVP 목표

- 핵심 기능인 데이터 업로드, 예측, 발주 추천을 먼저 완성한다.
- 이후 단계적으로 기능을 고도화한다.

## 2. MVP 후보 핵심 흐름

기술 문서에서 MVP 우선 개발 흐름으로 확인 가능한 범위는 다음과 같다.

```text
데이터 업로드
→ 예측
→ 발주 추천
```

## 3. MVP에 포함 가능성이 높은 기능

- CSV 또는 API 기반 POS 데이터 연동
- 메뉴 및 레시피 관리
- 초기 재고 등록
- 레시피 기반 재고 자동 차감
- 메뉴별 1-3일 수요예측
- 품목별 추천발주
- 점주 확인/수정/승인
- 추천발주 결과 조회
- 기본 대시보드

위 항목은 기술 문서상 핵심 기능으로 확인되나, MVP 포함 여부는 확정되지 않았다.

## 4. MVP에서 제한 검토가 필요한 범위

- 업종 범위를 카페/치킨집 등 단일 업종으로 제한
- 신규 매장 Cold-start 문제를 유사 매장 데이터 또는 업종별 일반화 모델로 대응
- 자동 발주 기능은 선택 사항으로 제공
- 실제 결제는 외부 사이트에서 진행

## 5. MVP 이후 고도화 후보

- 상세 매출 분석
- ROI 리포트
- 다중 매장 관리
- Enterprise 요금제 기능
- 고도화된 자동 연동
- TimExer류 외생변수 통합 모델 검토
- 경량 스트리밍 파이프라인 검토

- 데모 시나리오 정의 필요
- MVP 성공 기준 정의 필요
