# 시퀀스 설계서

## 1. 전체 시스템 흐름

```text
1. 사용자 요청
2. Frontend → Backend
3. Backend → DB 조회(AI예측시스템이 사전 생성한 결과 조회)
4. 결과 존재 → 바로 반환
5. 결과 없음 → AI Server 직접 호출 → 결과 생성 → DB 저장 → 반환
6. 자동발주 트리거 시 추천발주 조회
7. 점주 승인 화면 제공
8. 점주 확인/수정/승인
9. 발주 기록 저장
10. Playwright를 통해 쿠팡 장바구니에 자동으로 담기
11. 실제 결제는 쿠팡에서 진행
12. 판매 결과, 폐기 데이터, 점주 수정 이력 수집
13. n8n 스케줄링으로 AI 모델 재학습 트리거
```

## 2. 회원가입 시퀀스

```mermaid
sequenceDiagram
    participant 사용자
    participant 사주라UI
    participant 사주라서버
    participant DB

    사용자->>사주라UI: 구글 회원가입 시작
    Note over 사주라UI,사주라서버: Firebase Google 인증
    사주라UI->>사주라서버: 인증 토큰 전달
    사주라서버->>DB: 회원 존재 여부 조회
    DB-->>사주라서버: 조회 결과

    alt 신규 사용자
        사주라서버->>DB: 회원 정보 저장
    end

    사주라서버-->>사주라UI: 매장 정보 입력 요청
    사용자->>사주라UI: 매장 정보 입력
    사주라UI->>사주라서버: 매장 정보 저장 요청
    사주라서버->>DB: 매장 정보 저장

    사주라서버-->>사주라UI: 초기 설정 요청
    사용자->>사주라UI: 초기 재고 입력
    사주라UI->>사주라서버: 재고 등록 요청
    사주라서버->>DB: 재고 저장

    사용자->>사주라UI: 초기 메뉴 입력
    사주라UI->>사주라서버: 메뉴 등록 요청
    사주라서버->>DB: 메뉴 저장

    사용자->>사주라UI: POS 연동 정보 입력
    사주라UI->>사주라서버: POS 연동 요청
    사주라서버->>DB: POS 정보 저장

    alt POS 연동 성공
        사주라서버-->>사주라UI: 가입 완료
        사주라UI-->>사용자: 메인 화면 제공
    else POS 연동 실패
        사주라서버-->>사주라UI: 실패 응답
        사주라UI-->>사용자: 재시도 요청
    end
```

## 3. 수요예측 시퀀스

```mermaid
sequenceDiagram
    participant 사용자
    participant 사주라UI
    participant 사주라서버
    participant DB
    participant AI예측시스템

    par 사용자 조회 흐름
        사용자->>사주라UI: 수요 예측 화면 진입
        사용자->>사주라UI: 기간 설정
        사주라UI->>사주라서버: 예측 결과 요청
        사주라서버->>DB: 저장된 예측 조회
        DB-->>사주라서버: 결과 반환
        사주라서버-->>사주라UI: 결과 전달
        사주라UI-->>사용자: 예측 결과 표시
    and 사전 예측 수행
        Note over AI예측시스템: 주기적 예측 수행(배치)
        AI예측시스템->>사주라서버: 예측 결과 생성
        사주라서버->>DB: 예측 결과 저장
    end
```

## 4. 발주요청 시퀀스

```mermaid
sequenceDiagram
    participant 사용자
    participant 사주라UI
    participant 사주라서버
    participant DB
    participant AI예측시스템
    participant Playwright
    participant 쿠팡

    par 사용자 발주 흐름
        사용자->>사주라UI: 발주 요청 화면 진입
        사주라UI->>사주라서버: 추천안 요청
        사주라서버->>DB: 추천안 조회
        DB-->>사주라서버: 추천안 반환
        사주라서버-->>사주라UI: 추천안 전달
        사주라UI-->>사용자: 추천안 표시

        alt 사용자 수정
            사용자->>사주라UI: 수량/상품 수정
            사주라UI->>사주라서버: 수정 요청
            사주라서버->>DB: 수정안 저장
        end

        사용자->>사주라UI: 발주 확정
        사주라UI->>사주라서버: 발주 기록 저장 요청
        사주라서버->>DB: 발주 내역 저장
        사주라서버->>Playwright: 쿠팡 장바구니 자동 담기 요청
        Playwright->>쿠팡: 장바구니에 발주 목록 자동 추가
        쿠팡-->>Playwright: 담기 완료
        Playwright-->>사주라서버: 완료 응답
        사주라서버-->>사주라UI: 쿠팡 결제 진행 안내
        사주라UI-->>사용자: 쿠팡에서 결제 진행 안내 표시

    and 사전 추천 생성
        Note over AI예측시스템: 예측 기반 발주 추천안 사전 생성
        AI예측시스템->>사주라서버: 추천안 생성
        사주라서버->>DB: 추천안 저장
    end
```
