# 기능 목록

## 1. 기능 분류

| 대분류 | 기능 | 작성 가능 수준 |
|---|---|---|
| 인증/회원 | Google 로그인, 카카오 로그인, 회원가입, 매장 정보 입력 | 부분 작성 가능 |
| POS 연동 | CSV/API 연동, POS 어댑터, 스키마 검증, 이상치 탐지 | 부분 작성 가능 |
| 메뉴 관리 | 메뉴 등록/조회/수정/삭제, 메뉴명 중복 검증, 레시피 관리 | 부분 작성 가능 |
| 재고 관리 | 초기 재고 등록, 재고 조회/수정, 레시피 기반 자동 차감, 폐기 처리 | 부분 작성 가능 |
| 판매 데이터 | 기간별 판매 데이터 조회, 상세 조회 | 부분 작성 가능 |
| 수요예측 | 메뉴별 1-3일 수요예측, 배치 예측, 예측 결과 캐싱 | 부분 작성 가능 |
| 추천발주 | 품목별 권장 발주 수량, 예상 소진 시점, 점주 확인/수정/승인 | 부분 작성 가능 |
| 발주 실행 보조 | Playwright 기반 쿠팡 장바구니 자동 담기, 결제 안내 | 부분 작성 가능 |
| 대시보드 | 매출/예측 시각화, ROI 지표 제공 | 부분 작성 가능 |
| 데이터 파이프라인 | n8n 야간 배치, 수집/전처리/학습/예측/캐싱/알림 | 부분 작성 가능 |
| XAI | Feature Importance, SHAP, 자연어 근거, 신뢰도 경고 | 부분 작성 가능 |

## 2. 핵심 기능 목록

### 2.1 예측기반 발주 엔진

- 과거 매출, 날씨, 요일/공휴일, 지역 이벤트, SNS 노출도를 반영한다.
- 메뉴별 1-3일 예상 수요를 예측한다.
- 필요 재고량을 계산한다.
- 초기 재고는 1회 입력한다.
- 이후 판매 메뉴의 레시피 기반으로 식자재 사용량을 자동 계산한다.

### 2.2 품목별 추천발주

- 예측 판매량을 반영한다.
- 현재 재고를 반영한다.
- 레시피 소모량을 반영한다.
- 리드타임과 안전재고를 반영한다.
- 품목별 권장 발주 수량과 예상 소진 시점을 제안한다.
- 추천 사이트로 발주 정보를 전달한다.
- 실제 결제는 외부에서 진행된다.

### 2.3 점주 승인형 운영

- AI 추천발주안을 점주가 확인한다.
- 점주가 추천안을 수정할 수 있다.
- 점주가 최종 승인할 수 있다.
- 수정 이력과 실제 판매 결과를 다음 추천 정확도 개선에 반영한다.

### 2.4 소비기한 관리

- 식자재 소비기한을 자동 관리한다.
- 알림을 제공한다.
- 구체적 구현 방식은 확실하지 않음.

### 2.5 POS 어댑터

- TossPlaceAdapter를 제공한다.
- KiwoomAdapter를 제공한다.
- OKPOSAdapter를 제공한다.
- CSVAdapter를 제공한다.
- 각 POS 데이터를 Canonical Schema로 변환한다.

### 2.6 AI/XAI

- 이동평균, ARIMA/Prophet, XGBoost/LightGBM, LSTM, TimExer 순서로 베이스라인을 비교한다.
- LightGBM Feature Importance를 제공한다.
- SHAP 기반 개별 추천 근거를 제공한다.
- Top-3 영향 변수를 자연어로 변환한다.

### 2.7 자동화 파이프라인

- n8n이 매일 02:00에 배치를 실행한다.
- 수집, 전처리, 학습, 예측, 캐싱, 알림을 수행한다.
- 실패 시 Slack 알림을 제공한다.
